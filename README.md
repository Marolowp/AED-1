# 💻 Algoritmos e Estruturas de Dados 1 (AED-1)

Este repositório é dedicado ao armazenamento, organização e acompanhamento das atividades, listas de exercícios da disciplina de **Algoritmos e Estruturas de Dados 1** (AED 1) e resoluções de desafios de programação competitiva.

---

## 📁 Estrutura do Repositório

O projeto está organizado nas seguintes pastas principais:

* 📂 **`Listas/`**: Contém as listas de exercícios passadas em aula durante a cadeira (ex: Ponteiros, Alocação Dinâmica, Estruturas, etc.).
* 📂 **`LeetCode Solutions/`**: Resoluções de problemas e desafios da plataforma LeetCode praticados para reforçar a lógica e implementação de algoritmos.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem C**: Toda a disciplina e os exercícios são desenvolvidos nativamente em C.
* **GCC / Clang**: Compiladores utilizados para compilar e executar o código via terminal.
