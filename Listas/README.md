# 📝 Listas de Exercícios — AED 1

Este diretório contém a resolução dos exercícios e listas práticas propostos pelo professor ao longo do semestre na disciplina de **Algoritmos e Estruturas de Dados 1 (AED 1)**.

---

## 🎯 Objetivo

Praticar e fixar os conceitos fundamentais da disciplina através do desenvolvimento de algoritmos eficientes em **Linguagem C**.

---

## 📚 Conteúdos Abordados

As listas abordam tópicos essenciais de AED 1, tais como:

* **Ponteiros e Aritmética de Ponteiros**
* **Alocação Dinâmica de Memória** (`malloc`, `calloc`, `realloc`, `free`)
* **Estruturas (`struct`) e Tipos Abstratos de Dados (TAD)**
* **Listas Encadeadas** (Simplesmente Encadeadas, Duplamente Encadeadas e Circulares)
* **Pilhas (Stacks) e Filas (Queues)**
* **Recursão**
* **Algoritmos de Ordenação e Busca**

---

## 💻 Como Compilar e Executar

Para compilar e testar qualquer uma das listas localmente:

```bash
# Navegue até esta pasta
cd Listas

# Compile o arquivo desejado (exemplo: listas1.14.c)
gcc -Wall listas1.14.c -o exercicio

# Execute o programa
./exercicio
